### `docs/architecture.md`

```markdown
# Oreflow — architecture (why / what / how)

**Why:** field units drop scan exports in many shapes; downstream analytics needs one
normalized schema. Oreflow is the seam that absorbs that variety.

**What:** a small ingestion service — readers per source format, a normalizer, and a
writer to the analytics bucket.

**How:** `app/services/ingest.py` orchestrates; `app/services/auth.py` fetches the
upstream token; `app/utils/io.py` handles read/write. Auth currently uses a static
service token (tech debt — see notes-old.md).
```
